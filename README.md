# Bansal-Academy-s-Parent-App


A cross-platform parent engagement mobile application built with React Native CLI that provides real-time access to student attendance, academic performance, assignments, and parent-teacher communication. Integrated MongoDB and push notifications to deliver seamless updates and improve parental involvement in student learning.


- Developed a cross-platform HR management mobile app for Finewood and AGlobia Furniture using React Native CLI. Implemented user
authentication and role-based access (Admin, Staff, HR) with token-based login and secure API calls.

- Built core HR features including attendance tracking, leave requests, inquiry management, and profile management. Integrated React Native
libraries like react-navigation, axios, react-native-fs, react-native document-picker and react-native-vector-icon for smooth navigation, data
handling, and enhanced UI/UX.

- Designed clean, responsive UI with custom animations for a modern and intuitive experience. Implemented real-time API communication for live
updates and optimized performance. Delivered an exportable data and report feature for HR analysis and decision-making.
